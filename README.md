# myelia サブスク年間支出診断

ログイン・外部ライブラリ・サーバー処理のない静的Webプロトタイプです。`dist/index.html`、`dist/style.css`、`dist/app.js`をそのまま静的ホスティングに配置できます。

## 試す方法

1. `dist/index.html`をブラウザで開きます。
2. 契約中のサービスを3件以上選びます。一覧になければ名前を追加できます。
3. 各サービスの月額または年額を入力します。不明なら空欄のまま進めます。
4. 結果で月額換算・年間支出・未確認件数を確認します。
5. 見直し候補にチェックし、節約額を確認します。

料金はプリセットしていません。プランによる料金差を誤って確定しないためです。合計は入力済みの料金だけを使い、未確認の件数を結果に明示します。

## 画面設計

AppleのHuman Interface Guidelinesを参考に、重要な操作を上から順に配置し、サービス選択や次へ進むボタンに十分なタップ領域を設けています。選択数や「未確認」は文字でも伝え、音声読み上げ用のラベルも設定しています。ブランドは文字色 `#111318`、背景 `#F5F5F3`、アクセント `#6558E8`。提供されたロゴ画像のデザインをそのまま使用しています。日本語見出しはZen Kaku Gothic New、英語見出しはRaleway、操作画面はNoto Sans JP、金額と数字はManropeです。フォントはGoogle Fontsから読み込むため、インターネット接続がない場合は端末の代替フォントで表示されます。契約名や料金をフォントサービスに送る処理はありません。

## 10人での検証手順

- 対象：普段サブスクを表やアプリで管理していない社会人・家庭の人を中心に10人。
- 最初に「普段使っているサービスを選んで結果を見てください」とだけ伝え、操作を手助けしません。
- 観察：3件以上選べたか、料金を1件以上入力・修正できたか、結果画面を見たか、見直し候補にチェックしたか、迷った箇所。
- 終了後に「実際の支払いを確認したくなったか」「支出を見直す行動につながりそうか」を聞きます。契約名や金額を聞き出す必要はありません。
- 成功の目安（仮説）：10人中7人以上が3件以上選択、6人以上が料金入力、6人以上が結果到達、4人以上が解約シミュレーションを操作。少人数の探索的な目安であり、市場全体の推定ではありません。

## 簡単な計測

画面下の「操作記録をCSVで保存」で、操作イベントを本人の端末から任意で書き出せます。CSVには日時、ランダムなセッションID、イベント名、選択件数、料金確認済み件数だけが入り、サービス名・金額は入りません。実施者へ渡す場合は参加者の意思を確認してください。主なイベントは `selected_three`、`price_confirmed`、`result_viewed`、`simulation_changed` です。各参加者のCSVについて、これらが1回以上あるかを数えれば到達率を計算できます。

診断内容と操作記録は `localStorage` に保存され、サーバーには送信されません。「この端末の診断データを削除する」で両方を削除できます。ブラウザの保存を無効にしている場合、ページ再読み込み後の保持はできません。サイトの通常のアクセスログはホスティング事業者側で発生し得ます。

## 公開・費用

`dist/` を静的ホスティングに配置すれば動きます。バックエンドや有料APIは不要です。独自ドメインを使う場合のみ、その取得・更新費用が別途かかります。
